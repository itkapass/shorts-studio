Shorts Studio

A self-hosted tool that writes, renders and uploads short-form videos to its owner's own YouTube channel.

Privacy PolicyTerms of Service

What this application does

Shorts Studio is a personal, self-hosted video production pipeline. It runs on a schedule and performs the following steps automatically:

  • Writes a short video script using a text-generation model.
  • Generates a voiceover from that script using text-to-speech.
  • Renders a vertical 1080×1920 video with animated characters or licensed stock footage, plus burned-in captions.
  • Places the finished video in a review queue for a human to approve or reject.
  • Once a human approves it, uploads the video to the operator's own YouTube channel using the YouTube Data API v3.

Why it requests YouTube access

The application requests the youtube.upload scope for one purpose only: to upload finished video files to the YouTube channel belonging to the person operating the software.

This is single-operator software. Each person who uses Shorts Studio runs their own copy, with their own credentials, connected to their own YouTube channel. There is no shared service, no multi-tenant server, and no third party who receives access to anyone's account.

What it does not do

  • It does not read, list, modify or delete any existing videos on the account.
  • It does not access comments, subscribers, analytics, playlists or channel settings.
  • It does not access any other Google service — no Gmail, Drive, Contacts, Calendar or Photos.
  • It does not transmit Google user data to any third party.

Human review before publishing

No video is uploaded without a person explicitly approving it first. Automated quality checks reject broken renders before a human ever sees them, and a duplicate-concept check prevents the same idea being produced twice.

Open source

The complete source code is available to the operator, who self-hosts and runs it. There is no hosted version and no account to sign up for.
