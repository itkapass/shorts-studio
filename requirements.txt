# ── Image Processing (caption rendering) ──────────────────────────
# IMPORTANT — read before "fixing" this pin:
# moviepy==1.0.3's resize fx calls the PIL constant Image.ANTIALIAS,
# which Pillow 10+ removed, crashing every scene that goes through
# portrait-cropping. The real fix is in engine/styles/stock_footage.py:
# it no longer calls moviepy's resize fx at all (does the resize with
# PIL + Image.LANCZOS directly), so it works on any Pillow version.
# Do NOT "fix" this by pinning Pillow<10 — on Python 3.12+ there are no
# prebuilt wheels below 10.0, so pip falls back to a source build that
# needs libjpeg/zlib headers and is slow/fragile in CI. Leave this open.
Pillow>=9.0.0
# NOT numpy<2.0.0 — a previous version of this file capped numpy below 2.0,
# out of caution around moviepy 1.0.3 possibly not supporting it. Tested
# directly: moviepy 1.0.3 renders correctly under numpy 2.x. The cap was
# actively harmful in practice — on newer Python versions (confirmed on
# 3.14), there's no prebuilt wheel for numpy 1.26.4 (the last 1.x release,
# which predates 3.14 entirely), so pip fell back to a source build that
# then failed outright without a C compiler installed. Whatever numpy
# torch/whisper already pulled in works fine; don't force a downgrade.
numpy>=1.24.0

# ── Timezone data ──────────────────────────────────────────────────
# Needed by engine/daycycle.py, which keys the Gemini daily-quota counter
# on the PACIFIC date because that is when Google's allowance resets.
# Linux (and the GitHub Actions runner) ships a system tz database, so this
# is really here for Windows, where zoneinfo has no system source and

# release exists to fix.
